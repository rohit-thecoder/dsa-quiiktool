# Architecture
Next.js statically enumerates curriculum pages from the shared catalog. The search route serves a compact JSON index on demand. Educational pages render their reading material on the server.

A problem owns validation constraints, approaches, reference listings and fixtures. Trusted TypeScript runners emit immutable execution frames. The worker handles new inputs and the client timeline selects a frame for both panels. Game engines expose deterministic legal moves and victory conditions separately from their React boards.

The local progress schema stores completion dates, per-level scores, study preferences, first attempts and review intervals. Settings accepts only validated JSON backups. No account or application database is required.
