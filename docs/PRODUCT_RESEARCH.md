# Product research
These observations concern the public learning experience. The implementation and exercises were independently authored.

| Public resource | Observation | Design decision |
|---|---|---|
| [VisuAlgo](https://visualgo.net/en) | Animations and training make internal operations visible. A novice also needs to explain a decision. | Pair replay with an explicit decision and variable watch. |
| [NeetCode roadmap](https://neetcode.io/roadmap) | Its topic graph gives practice a recommended order. | Offer workload-based schedules and keep all topics accessible. |
| [LeetCode study plans](https://leetcode.com/studyplan/) | Curated collections provide repeatable practice. A list alone does not show how memory changes. | Open each problem into a runtime trace. |
| [Striver A2Z](https://takeuforward.org/prep-hub/strivers-a2z-dsa-sheet) | A long topic sequence and progress counts help organize placement study. | Use local records and portable backups for account-free practice. |
| [Brilliant](https://brilliant.org/) | Guided questions on a shared visual surface encourage learners to commit to an answer. | Use deterministic prediction exercises with explanations. |
| [Algorithm Visualizer](https://github.com/algorithm-visualizer/algorithm-visualizer) | Connects program execution with visual output. | Generate bounded traces from trusted runners with editable data. |
| [Computer Science Field Guide](https://www.csfieldguide.org.nz/en/interactives/) | Short purpose-built simulations isolate one idea. | Give every arcade level a specific legal move and observable win condition. |
